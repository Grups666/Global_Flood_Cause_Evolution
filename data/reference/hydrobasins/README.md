# HydroBASINS reference layers

This directory contains HydroBASINS standard polygon archives, version 1.c,
for Pfafstetter level 5 and the continental regions needed for the global
catchment sample. Levels 3 and 4 are outside the declared analysis design and
are not stored here.

- Official product page: <https://www.hydrosheds.org/products/hydrobasins>
- Technical documentation: <https://data.hydrosheds.org/file/technical-documentation/HydroBASINS_TechDoc_v1c.pdf>
- Download date: 2026-08-17
- Stored format: official ZIP archives without modification

HydroBASINS is distributed under the HydroSHEDS license described on the
official product page and in its technical documentation. File sizes and
SHA-256 hashes are generated by the local-analysis stage in
`outputs/logs/hydrobasins_reference_sha256.csv`.
