# Figure design map

All figures use one restrained diverging scale: blue for decreases, warm orange for increases and a pale neutral centre. Unsupported but estimable directions are subdued; supported results are saturated and plotted above them. Figure titles state the physical question rather than an internal variable name.

| Figure | Scientific purpose | Visual form |
|---|---|---|
| 01 Sample and process coverage | Show observed-catchment coverage and the six-process composition of Q95 events | global point map + horizontal composition bars |
| 02 Overall flood changes | Separate changes in direct stormflow volume, daily peak and Q95-event frequency | three aligned catchment maps |
| 03 Process-frequency changes | Locate catchments where a mechanism produced large floods more or less often | six mechanism-specific catchment maps |
| 04 Process-share changes | Locate shifts in the mechanism composition of each catchment's upper tail | six mechanism-specific catchment maps |
| 05 Process-response rankings | Compare the largest supported changes in mechanism-specific volume and peak | two signed horizontal rankings |
| 06 Example trajectories | Make percentage-point process-share effects concrete | observed annual shares + fitted binomial trajectories |

PNG files are used for browser reading. Matching SVG files are retained for manuscript editing. Decorative four-dot marks are not used.
