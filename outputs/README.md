# Generated Outputs

## `tables/`

CSV audit and result tables. File names describe the grain and estimator; there
are no `final`, `v1`, or `revised` variants.

## `figures/`

Each figure is exported once in two delivery formats with the same stable base
name:

- PNG: report and quick review;
- SVG: manuscript editing and vector export.

## `logs/`

Machine-readable JSON execution receipts.

All output directories are reproducible and ignored by version control.
